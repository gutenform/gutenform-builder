# Settings

Gutenform settings are organized in a sidebar navigation.

## Mailboxes

Create and manage mailboxes. See [Mailboxes](mailboxes.md).

## Providers

Configure where form submissions go. See [Providers](providers.md).

## Labels

Manage entry labels. See [Labels](labels.md).

## SMTP

Configure email delivery for the Email provider:
- SMTP host and port
- Authentication (username/password or app password)
- From email and name
- Test connection to verify settings

## Debug

Enable or disable debug mode for troubleshooting. When enabled, additional logging may be available.

## Skip First Steps

Users can skip the welcome/onboarding checklist. This setting stores the user's preference to go directly to the Inbox on subsequent visits.

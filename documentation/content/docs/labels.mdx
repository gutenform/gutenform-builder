---
title: Labels
description: Entry labels for organization
---

Labels help organize and categorize form entries. Similar to email labels or tags.

## Features

- **Custom Labels**: Create labels with custom names and colors
- **Color Coding**: Each label has a color for quick visual identification
- **Filter by Label**: Filter Inbox entries by one or more labels
- **Drag & Drop**: Drag entries onto labels in the sidebar to assign
- **Label Management**: Add, edit, delete labels in Settings > Labels

## Default Labels

On first setup, default labels may be created (e.g., Important, Follow-up). These can be customized or removed.

Gutenform is a WordPress form builder plugin that uses Gutenberg blocks to create forms. Form submissions are collected in an inbox-style interface with support for labels, statuses, and multiple providers.

## Quick Start

1. **Install**: Activate the plugin in WordPress
2. **Setup**: Follow the welcome checklist to configure your first provider, mailbox, and labels
3. **Build**: Create a page and add the Form block with input fields
4. **Manage**: View submissions in the Inbox
